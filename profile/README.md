## What we build

MASAKA gives agents an observable, interruptible, and verifiable browser runtime:

- launch isolated browser sessions and send real input to web pages;
- watch agent activity in real time and take over when needed;
- verify each step with screenshots, page state, and structured results;
- manage browser sessions, configuration, usage, and team workflows in one place.

## Jet Browser

[Jet Browser](https://github.com/masakaai/jet-browser) is a lightweight WPE WebKit runtime for agents, with native input, screenshots, and an ordered JSONL interface. The core runtime can be deployed independently without requiring MASAKA's hosted control plane, an account, or a model provider.
