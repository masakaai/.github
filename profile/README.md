## 我们在做什么

MASAKA 为智能体提供可观察、可接管、可验证的浏览器运行环境：

- 启动隔离的浏览器会话，并在网页中执行真实输入；
- 实时查看智能体的操作过程，必要时由人工接管；
- 使用截图、页面状态和结构化结果验证每一步；
- 将浏览器会话、配置、用量和团队协作集中到同一工作区。

## Jet Browser

[Jet Browser](https://github.com/masakaai/jet-browser) 是一个面向智能体的轻量级 WPE WebKit 浏览器运行时，提供原生输入、截图和有序 JSONL 接口。核心运行时可以独立部署，不强制依赖托管控制平面、账号或模型服务。
