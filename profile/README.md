## Welcome

The official MASAKA Discord is the public meeting place for developers building browser agents and reliable web automation. Join to:

- get help with MASAKA integrations;
- share browser-agent workflows and implementation patterns;
- discuss live browser control and human handoff;
- report community-level feedback and help shape the product.

**Permanent invite:** https://discord.gg/8Ybc32NcMt

MASAKA 的官方 Discord 面向浏览器 Agent 与 Web 自动化开发者，欢迎交流集成方案、浏览器接管流程和产品反馈。

## Community safety

Start in `#rules`, then continue in `#general`. Be respectful, stay on topic, and use browser automation only where you have authorization.

Never post passwords, API keys, session cookies, payment details, saved credentials, or personal data. MASAKA staff will not ask for them in Discord.

For account, billing, privacy, cancellation, or refund requests, use [customer support](mailto:masaka-ai-sup@outlook.com) rather than a public channel.
